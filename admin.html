أدخل الاسم والرابط، وأضف صورة معاينة — وسيظهر مباشرة في قسم الأعمال.

كيف تشتغل اللوحة؟

  1. عدّل أي نص بالعربية أو الإنجليزية من التبويب المناسب.
  2. اضغط حفظ التعديلات — بيتم تحديث content/site.json مع نسخة احتياطية تلقائية.
  3. لإضافة صورة، ارفعها من نفس الحقل؛ بتنحفظ في assets/uploads/.
  4. للتراجع عن أي تعديل، استخدم زر تراجع أو تبويب النسخ الاحتياطية.

لو اللوحة مفتوحة بدون السيرفر (node server.js)، الحفظ بيتم في المتصفح فقط. شغّل السيرفر للتعديل المباشر على الملفات.

النشر على GitHub

غير مُفعّل

فعّل الوضع ده عشان تحفظ مباشرة في ريبو GitHub — مفيد لما تفتح اللوحة من abdelkaioumm.github.io/portolio1/admin.html من أي جهاز.

إزاي أطلع التوكن؟ (خطوات)
  1. افتح Fine-grained token جديد.
  2. Repository access → اختر Only select repositories → الريبو بتاعك.
  3. Permissions → Contents → Read and write.
  4. اضغط Generate، وانسخ التوكن (بيظهر مرة واحدة بس).
  5. الصقه هنا واضغط «اختبار الاتصال».

التوكن بيتخزن في المتصفح ده بس (localStorage) وما بيتبعتش لأي مكان غير api.github.com.
